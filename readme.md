# Research and Design of Multi-Input Multi-Output (MIMO) Wireless Communication Systems [with MATLAB Code and Report]

Introduction Until the early 1990s, most wireless communication work was concentrated at one end of the wireless link, typically with an array of antennas on a receiver. Gerard J. Foschini and Michael J. Gans, Foschini and Emre Telatar demonstrated that for highly scattering environments, significant capacity gains could be achieved by using multiple antennas at both ends of the transmission channel. Another approach involved using multiple transmit antennas and only optional multiple receive antennas. Vahid Tarokh, Nambi Seshadri and Robert Calderbank proposed these space-time codes to achieve significant error rate improvements over single-antenna systems. Xiaywa Shālmī, as well as later developments by Wahid Tarollah, Hamid Jafarihani, and Robert Calderbank, developed the first Space-Time Block Code (STBC). Space-time coding involves the transmission of multiple redundant copies of data to compensate for fading and thermal noise, hoping some of them can arrive at the receiver in better states than others. In the case of space-time block codes, the data stream to be transmitted is coded into blocks distributed between separated antennas and across time. While having multiple transmit antennas is necessary, having multiple receive antennas is not. The increase in the number of receive antennas improves performance. This process of receiving different data copies is known as diversity reception, which has been widely studied since Foschini's 1998 paper. Today, all wireless technology prototypes are conducted on software-defined radios. Therefore, to understand the architecture and operation of software-defined radios, we must refer to multiple papers [1, 2, 8, 9, 10, 11, 12]. Most of these papers, while focusing on MIMO-OFDM systems, contain extensive information on the design of MIMO systems.
Wireless communication systems are characterized by two main parameters: throughput and/or reliability. As we move towards the fifth-generation mobile communication systems, there is a challenge to meet lower power, higher throughput, longer range, and more reliable link requirements. The concepts in MIMO systems are crucial for the development of various wireless technologies today (e.g., 4G LTE and 802.11ac/ad). We have indeed seen performance improvements due to the use of this technology.
Starting with understanding the wireless communication system and channel conditions is essential for simulation and implementation projects. Understanding how the channel affects the transmitted signals is a prerequisite for simulation and implementation of wireless communication systems. Firstly, simple SISO system simulations are conducted to understand the impact of the channel. Then, we begin to understand the effects of transmit and receive diversity, as well as the improvement in system performance due to the increase in diversity. Maximum ratio combining (MRRC) is a popular technique considered one of the best receiving diversity techniques. We have explored the work of space-time block codes, including the Alamandro technique, under actual channel conditions and compared their performances. Additionally, different decoding strategies were simulated to gain an understanding of the best channel effect and noise reduction through transmit and receive diversity. We implemented an SISO wireless communication system using B210 software-defined radio (SDR). The Alamanti 2x1 and 2x2 system designs were implemented and functional tests were carried out. All SDR designs were implemented on GNU Radio. The implementation included designing both the transmitter and receiver on the GNU Radio platform. GNU Radio is an open-source radio simulation software with SDR compatibility and provides free access to implement data processing modules using a user-friendly interface.
The conclusion that the deterministic free-space path loss model using antenna parameters, wavelengths, and distance from the transmitter is insufficient to represent the channel is valid. This model does not consider the impact of fading in the actual channel. To illustrate the signal variations caused by multipath effects, a Rayleigh/Rician channel model was used. The Rayleigh channel model is useful for describing small-scale fading effects without dominant line-of-sight components, while the Rician model describes the fading process when there are dominant LoS components. In SISO systems, their performance on an actual Rayleigh channel is significantly worse than on an AWGN channel. To reduce the probability of deep fading in the Rayleigh channel, we attempted to solve this problem by using multiple antennas. Various diversity techniques involving transmission and reception diversity or both were compared. As the number of diversity stages increased, the system's bit error rate-SNR characteristic improved. Communication systems with different decoding strategies were compared. The various equalization strategies used were zero-forcing (ZF), minimum mean squared error (MMSE), and maximum likelihood (ML) decoding. Continuous interference cancellation (SIC) was used to improve the above decoding techniques. Optimal sorting technology was employed to further enhance the algorithm's performance. However, the ML method outperformed all the above methods.
MIMO frame synchronization, data frame synchronization, Alamplitude 2x1 and 2x2 decoders, Alamplitude encoders, channel estimation and equalization (sub-blocks) have been verified to work in actual simulation runs, with data recovery accuracy of 99% or higher. Due to the challenges of SDR performance, the system could not receive sufficient clear and robust signals for error-free decoding in most trial runs. However, under good performance conditions, results as shown in the analysis section above were obtained.
